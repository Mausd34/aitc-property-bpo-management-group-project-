# 📊 Reports Module - Complete Management Guide

## Overview
The Reports module manages all system reports for tracking, analysis, and documentation of property preservation and BPO management activities.

### Report Model Fields
- **id**: Unique identifier (auto-generated)
- **report_type**: Type of report (e.g., "Work Order Summary", "Vendor Performance", etc.)
- **generated_by**: User who generated the report (Foreign Key to User)
- **generated_date**: Timestamp when report was created (auto-generated)
- **file_path**: Path/URL to report file (optional)

**Request:**

## 🚀 Advanced Usage

### Automated Report Generation
Use Django Celery to schedule reports:
```python
# celery_tasks.py
@periodic_task(run_every=crontab(hour=0, minute=0))
def generate_daily_report():
    report = Report.objects.create(
        report_type="Daily Summary",
        generated_by_id=1,
        file_path=generate_pdf_report()
    )
    return f"Report {report.id} generated"
```

```bash
# Get all reports

curl -X POST http://127.0.0.1:8000/api/reports/ \
  -H "Content-Type: application/json" \
  -d '{"report_type":"Test Report","generated_by":1,"file_path":"/test.pdf"}'

# Update report

  -H "Content-Type: application/json" \
  -d '{"report_type":"Updated Report"}'

```

### Using PowerShell
```powershell
# Get all reports
Invoke-WebRequest -Uri "http://127.0.0.1:8000/api/reports/" -UseBasicParsing | ConvertFrom-Json

# Create report
$body = @{
    report_type = "Test Report"
    generated_by = 1
    file_path = "/test.pdf"
} | ConvertTo-Json

Invoke-WebRequest -Uri "http://127.0.0.1:8000/api/reports/" `
  -Method POST `
  -Body $body `
  -ContentType "application/json" `
  -UseBasicParsing
```
